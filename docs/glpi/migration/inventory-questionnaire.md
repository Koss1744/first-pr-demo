# Опросник: что есть перенести в GLPI

**Кому:** ИТ-руководитель HOFI
**Время на заполнение:** 15 минут
**Просим вернуть до:** 2026-10-02 (вопрос 5.4 — до **2026-09-18**, он влияет на дату запуска)
**Выгрузки и подсчёты не нужны.** Везде, где спрашивается количество,
достаточно порядка величины. «Не знаю» — допустимый ответ, но тогда укажите,
пожалуйста, кто знает.

**Зачем:** по этим ответам мы за один заход определим объём миграции. Сейчас
оценка блока «миграция данных» лежит в диапазоне 0–10+ человеко-дней —
после опросника она сузится до 2–3 дней разброса. На запуск приёма заявок
(Релиз 1) опросник не влияет: он идёт параллельно.

Как заполнять: отметьте подходящие варианты `[x]`, свободные поля — одной
строкой. Решения принимать не нужно — только описать, что есть.

## Что будет после опросника

1. Мы сводим ответы в [decision.md](decision.md) и по каждому типу данных
   даём решение «переносим / не переносим» с ценой и альтернативой.
2. Заказчик утверждает решения — по каждому типу отдельно, не пакетом.
3. Оценка миграции сужается с 0–10+ до диапазона в 2–3 дня, и блок встаёт
   в план проекта.
4. Релиз 1 (приём заявок с почты, выход 2026-10-16) идёт своим темпом и не
   ждёт результатов опросника — кроме вопроса 5.4.

**Если на часть вопросов ответить не получается — не задерживайте опросник.**
Пришлите что есть, отметив неизвестное; по каждому неотвеченному пункту
действует вариант по умолчанию из [decision.md](decision.md), раздел 5.
